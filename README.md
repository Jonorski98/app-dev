# My Favorite Movie

## Iron Man (2008)
I like this movie because it is the start of the Marvel Cinematic Universe. It shows how Tony Stark built his first suit using scrap materials to escape from his captors.

### Movie Details
* Director: Jon Favreau
* Genre: Action / Sci-Fi

### Main Characters
1. Tony Stark - The billionaire who became Iron Man
2. Pepper Potts - Tony's trusted assistant

> "I am Iron Man." - Tony Stark
